# Ice Cream Parlour Billing System

Full Stack Billing & Inventory Management System built with:

- React.js
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

## Features

- Role Based Login
- Product Management
- Customer Management
- Billing & Invoice Generation
- Inventory Tracking
- Sales Reports
- Profit Reports

## Installation

### Backend

npm install
npm run dev

### Frontend

npm install
npm run dev
